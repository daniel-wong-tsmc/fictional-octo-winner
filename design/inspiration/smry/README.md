# smry.ai reference capture

Source of visual inspiration for the workflow platform. Captured 2026-11-14.

- `dembrandt-*.json`, `tokens.dtcg.json`, `dembrandt-DESIGN.md`: output of dembrandt 0.39.2 against https://smry.ai/home (light and dark).
- `sidebar-measurements.json`: computed styles of the left sidebar, measured with Playwright at 1440x900.
- `sidebar-reference.png`: the sidebar picked as the model for navigation.
- `home-light.png`, `home-dark.png`: viewport screenshots.

Reference data only. The design system of record is the Astryx theme built from these values.
